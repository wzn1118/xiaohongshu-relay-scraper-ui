# 2026-08-10 公共发布版更新说明

## 发布目标

本次版本以“公网可运行、左侧按操作顺序导航、右侧只显示当前模块、真实功能可追溯、公共包不携带机器私密状态”为发布目标。它打包当前工作树中的全部最新源代码，而不是只打包上一次 Git 提交。

## 用户界面

- 工作台引入 `start / setup / task / workspace / history / artifacts` 六类 Screen；
- 左侧导航按总览、环境、新建、结果、投递、历史、文件排列；
- 右侧主屏只展示当前模块；
- 历史任务打开后自动进入对应工作区；
- 默认展示任务固定为 `20260804081657-caf8f451`，存在该任务数据时优先选中；
- 采集连接相关文案由内部术语 “Relay” 调整为用户能理解的“采集浏览器”；
- AI 入口文案区分本机模型和“自定义 AI 接口（OpenAI 兼容）”；
- 新增未保存投递正文的离开保护。

## 投递与文案

- “编辑正文”同时编辑邮件标题、邮件正文和 Cover Letter；
- 保存后写入新的草稿版本并更新当前发送预览；
- 邮件标题按照正文中的标题要求、岗位要求和附件要求进行结构化解析；
- 标题或正文变化后，旧预演和冻结结果失效，必须重新预演；
- 批量列表补充标题来源、命名规则、复核原因和状态展示；
- 加强岗位来源分类，减少不属于真实投递机会的数据进入发送流程；
- 批处理支持外部 OpenAI 兼容 API、并发生成、质量复核、自动重写和逐条持久化。

## AI 接入

- AI 连接不再以“模型列表可读取”作为成功标准；
- Session 创建后执行真实推理 Probe，返回实际模型和延迟；
- 对短暂网络传输错误进行有限次数重试；
- 对认证、权限、路由和模型不存在等确定性 HTTP 错误直接返回；
- 支持本机模型以及自定义 OpenAI 兼容接口；
- 服务端错误映射保留可操作原因，避免统一显示为不可理解的失败信息。

## MCP

- 新增完整 MCP HTTP 服务与 stdio Bridge；
- 公共发布包新增 `start-mcp.cmd` 一键启动入口、`mcp-stdio.cmd` 便携桥和 `verify-mcp.cmd` 官方 SDK 验证入口；
- 新增无凭据客户端模板 `config/mcp-client.example.json` 与机器可读的 `MCP_PACKAGE_INFO.json`；
- 发布脚本把 MCP 服务端、管理 UI、桥接器、验证器、模板和使用指南列为强制归档文件；
- 新增 MCP 管理 UI；
- Grant 绑定上下文、工具、资源、Scope、风险上限和过期时间；
- 新增调用限速、并发控制、Session 空闲回收和输出上限；
- 新增审批、Idempotency、上下文 Hash、运行记录和审计；
- 备份恢复与私有迁移会撤销旧 Grant；
- MCP 监听强制限制在回环地址，公网 Tunnel 不代理 MCP。

## 任务和数据

- 修复历史 Workflow State 路径和状态恢复边界；
- 补充 Revision 校验，防止旧状态覆盖新状态；
- JobManager 增加持久任务和恢复测试；
- 补充数据来源、状态和阻塞原因字段；
- Data Copilot 持久存储、审批和运行记录增强；
- 数据删除、保留策略和诊断能力继续保留在受保护 API 中。

## 生产运维

- 生产启动支持复用已有 Tunnel、无浏览器和非交互模式；
- 新增生产看门狗与更严格的进程归属检查；
- 启动注册、备份和恢复脚本增强；
- 公共/私有包边界分离；
- 公共包排除数据、Cookie、管理员账号、MCP Pepper、AI/SMTP 配置和 Tunnel 凭据；
- 私有迁移包支持撤销 MCP Grant 和生成私密排除清单；
- 便携运行时新增完整 Chromium 要求；
- 大体积便携运行时改为在目标归档所在磁盘暂存，避免跨盘复制在系统盘受限时生成不完整运行时树；
- 归档生成后检查必需文件和禁止路径，并输出 SHA-256。
