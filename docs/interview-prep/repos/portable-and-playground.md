# 一页项目卡：便携版与 Playground

## today-you-applied-portable

主项目的 Windows 产品化快照：Node/Python/browser runtime、一键启动、首次配置、健康检查和净化发布。README 中数据量是包内快照，不是业务 KPI。

## feishu-openai-bot

FastAPI + Feishu Events + OpenAI Responses API + SQLite。适合讲 webhook、消息幂等、模型调用和轻量会话状态。

## secondary-brightness-widget

PowerShell/WPF + DDC/CI。适合讲 Windows 单实例、显示器枚举、硬件边界和启动项。

## xhs_scraper

Python Relay + JSON/CSV/XLSX 的早期采集原型。适合讲从“导出脚本”演进到 job/checkpoint/ledger/SSE 的原因。
