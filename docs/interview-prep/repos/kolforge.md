# 一页项目卡：KOLFORGE

## 定位

多平台 KOL 发现、内容证据分析、个性化建联和营销报告工作台。

## 栈

React/Vite/JavaScript、Node ESM、Python、Relay/CDP、FFmpeg、OCR、Whisper/Ollama、OpenAI-compatible API、MCP。

## 主链

品牌目标 → query routes → platform connectors → canonical creator/content → ASR/OCR/评论 evidence → 七代理分析 → 个性化消息/报告。

## 亮点

- connector 不直接接收浏览器 Cookie/Relay session。
- 平台账号和内容的 canonical schema、跨路线去重。
- checkpoint、受限并发、超时和重试。
- session-forensics 将 agent session 编译为证据化流程。
