# 压力追问与纠偏训练

这份清单用于模拟“面试官怀疑夸大”的场景。每题先回答事实，再回答推论，最后给出补证动作。

2. 当前工作树有大量未提交文件，哪些能力已经进 v3.0？
3. 为什么 main 与 remote 默认分支不一致？
4. phase7 和 portable clone 是两个项目还是历史快照？
5. MKT大师没有 commit，如何证明它不是拼接的目录？
6. wechat 仓库的 remote 指向他人，你为什么把它放进简历？
7. Asteria 的方法数量是代码扫描结果还是 README 数字？
8. Hegel Salon 的语料来源和授权如何说明？

## 标准纠偏句式

- “这条是当前文件已核验事实。”
- “这条来自 2026-08-01 的历史验收报告，本轮没有重跑。”
- “这是 README 的容量目标，不是生产指标。”
- “这部分在当前工作区未提交，应该称为实验扩展。”
- “这个仓库 remote 指向外部项目，我只能把它表述为源码阅读。”
- “我会用日志、commit、fixture 或 dated report 补证，而不是猜一个数字。”
