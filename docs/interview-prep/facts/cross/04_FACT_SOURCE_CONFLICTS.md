## 8. 易变公开元数据

GitHub API 的 `stars`、`forks`、open issues、default branch、更新时间和仓库可见性会随时间变化。[公开 GitHub 元数据快照](./02_PUBLIC_GITHUB_METADATA.md)只代表 2026-08-18 查询时点。面试材料若不需要社区影响力，优先省略这些数字；若需要，带上查询日期并在面试前刷新。

## 9. 个人贡献归属

以下三句话分别代表不同证据强度：

1. “仓库代码实现了 X”：适用于代码事实。
2. “我能逐行解释并参与了 X”：需要候选人自己确认参与范围。
3. “我独立设计并交付了 X”：需要提交、PR、issue、设计稿、会话记录或可核验产物支撑。

事实库只直接支持第一类。第二、第三类必须由候选人根据真实经历补齐。
