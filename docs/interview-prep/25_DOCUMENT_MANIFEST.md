## 4. 使用说明

- `facts/main/` 是精确机械清单，体量最大；只在追问具体路径、符号、配置、依赖或状态时加载。
- `facts/xhs/` 是主仓库按主题整理的编号事实；适合作为主项目深挖的首选证据层。
- `facts/local/` 与 `facts/public-external/` 分别处理未版本化本地项目和外部/公开源码的归属边界。
- 根目录 `00` 到 `24` 是面试叙事与训练层；事实冲突时回查带版本和日期的事实层。
